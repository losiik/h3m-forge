# h3m-forge

Библиотека для чтения, записи и генерации карт Heroes of Might and Magic III
(`.h3m`), с прицелом на формат Horn of the Abyss.

Конечная цель — дать ИИ-агентам возможность создавать осмысленные карты:
не расставлять байты, а описывать замысел («зона старта, средняя охрана,
связана с третьей зоной через монолит»), а всю геометрию и бинарную упаковку
берёт на себя библиотека.

## Статус

В работе. Есть ридер/райтер и первый генератор миров для HotA из описания зон.

## Генератор миров HotA

Независим от сценария «Одиссеи». Вход — JSON с зонами, их почвами,
стартовыми игроками и связями. Выход — **родной формат HotA 1.8.0,
подверсия 9**, карта `.h3m` и отчёт `.report.json`.

После установки проекта:

```powershell
python tools/make_world.py examples/archipelago.json --output out/archipelago.h3m
python tools/make_world.py examples/archipelago.json --seed 123 --output out/archipelago-123.h3m
```

Пример: [examples/archipelago.json](examples/archipelago.json). Название, размер
(72, 108, 144), seed, набор из 2–8 зон, их почвы и связи редактируются в JSON.
Каждому игроку нужна ровно одна стартовая зона; номера игроков идут от 0
без пропусков, игроков минимум два. Связи должны объединять все зоны.
`decoration_density` задаётся от 0 до 0.4. Неизвестные поля отклоняются.

Генератор создаёт острова с широкими сухопутными переходами, стартовые города,
лесопилки, рудники, ресурсы, сундуки и наборы декора по биомам. Переходы почв
и береговые тайлы подбираются по окружению 3×3 из установленных карт вместе
с флагами отражения. Если подходящего образца нет, генерация завершается
ошибкой. Каталог кэшируется в `out/world-assets.json` и пересчитывается при
изменении исходных карт. Первый запуск существенно дольше повторных.

Проверяется полный разбор файла, побайтовая пересборка, отсутствие пересечений
занятых клеток объектов и доступность зон и южных подходов к интерактивным
объектам после размещения декора. Проверка проходов использует только шаги
по сторонам клеток, без зависимости от возможности срезать угол.

Это первая основа генератора, а не законченный генератор приключений:
пока один наземный слой, без плавания, охраны, баланса боёв, дорог, квестов
и скриптов. Связи гарантируют доступ, но не запрет обхода и не порядок
прохождения. Геометрия размещает зоны по окружности. Произвольные формы,
подземелье и обязательные охраняемые проходы требуют следующих алгоритмов.
Прохождение партии в игре пока не проверено.

Базовый `h3m.generate.new_map()` сохраняет формат SoD для прежних инструментов;
новый `h3m.hota.new_map()` и `h3m.world.generate_world()` создают HotA.

| Фаза | Что                               | Статус                |
|------|-----------------------------------|-----------------------|
| 0    | Каркас, логирование, журнал       | готово                |
| 1    | Ридер `.h3m` (все версии)         | готово для RoE/AB/SoD |
| 2    | Райтер и round-trip               | готово                |
| 3    | Генерация карты с нуля            | готово                |
| 4    | Карта по мотивам «Одиссеи»        | в работе              |
| 5    | MCP-сервер с семантическим API    | 10 инструментов, stdio; просмотр наград и правка отрядов |

Сгенерированные карты открываются в редакторе HotA: пустая, с объектами и со
стартовыми городами — проверено вручную.

**RoE, AB и SoD разобраны полностью — 100% байтов.** Каждая из 157 карт этих
форматов читается до последнего байта и собирается обратно побайтово.

| формат | карт | round-trip | разобрано |
|--------|------|------------|-----------|
| RoE    | 47   | 47/47      | 100% |
| AB     | 54   | 54/54      | 100% |
| SoD    | 56   | 56/56      | 100% |
| HotA   | 64   | 64/64      | 68%  |
| всего  | 221  | 221/221    | 88%  |

У HotA остались собственные надстройки над несколькими типами объектов:
хижина провидца, герои, события, монстры.

## Как проверяется корректность

Ключевая идея проекта — **round-trip побайтово**:

```
оригинал.h3m → ридер → структура → райтер → новый.h3m
                                               ↓
                            сравнение с оригиналом байт в байт
```

Если реальная карта из поставки игры разбирается и собирается обратно без
единого расхождения, значит формат понят точно, а не «примерно похоже».
Это доказывает сохранность байтов, но не правильную интерпретацию каждого
поля: непрочитанные блоки могут сохраняться сырым хвостом, а симметричная
ошибка чтения/записи тоже выдержит round-trip. Поэтому отдельно проверяются
полнота разбора, семантика карты и открытие в редакторе.

Второй инвариант, бесплатный и очень полезный: парсер обязан дойти ровно до
конца потока. Остался лишний байт или не хватило — значит где-то поехало
смещение.

Тестовая база — 221 карта из поставки HotA 1.8.0.

## Сюжетная «Одиссея» для HotA

```powershell
$env:PYTHONPATH='src'
python tools/make_odyssey_story.py
```

Результат: `out/Odyssey-Homecoming-Compact.h3m` («Одиссея: тесные проливы»), руководство с маршрутом `.md`
и отчёт проверок `.report.json`. Это отдельное приключение 72×72 с морем,
13 основными островами, отдельной стоянкой у огней Итаки, подземным царством теней
и последовательностью эпизодов мифа. Семь проливов открываются по факту победы
над конкретным отрядом, без доставки трофея. Рифы и стражи закрывают будущие острова.
Всего 23 столкновения: 14 полевых отрядов (семь морских), три охраняемых склада
и шесть необязательных испытаний. Осталось девять разговоров и заданий:
подготовка побега от Полифема, Эол, Кирка, Тиресий, жертва Сцилле, плот и Пенелопа.
Подсказки в первый день и в 13 морских стоянках объясняют ближайшую задачу.
У Одиссея меньше стартовое войско, четыре боевых заклинания и надетая шляпа
адмирала для посадки и высадки без потери всего хода. Рекомендуется 100%.
Переработка 4 сокращает площадь вчетверо. Суммарное расстояние морских переходов
в одной консервативной модели уменьшено с 886 до 351 шага; самый длинный — 29.
Это расстояния в клетках, а не измерение игровых дней. На берегу до южного
подхода к действию — не более десяти шагов от пляжа. Три дополнительных
провидца предлагают заплатить за подготовку вместо боя за припасы;
необязательные испытания лотофагов и сирен дают Точность и Лечение.
После отзыва о недоступном Полифеме исправлен расчёт береговых флагов:
все 14 пристаней проверяются отдельно от модели обходов, результат в `landings`.
Прежнюю версию пользователь прошёл за 20 минут; оценка 2–4 часа не подтвердилась.
Длительность и полный боевой баланс переработки 4 ещё не измерены.
Годы и кораблекрушения рассказаны текстом; после кары Зевса армия условна.
Старый прототип `tools/make_odyssey.py` и предыдущий генератор `odyssey.story.generate`
сохранены. CLI и MCP теперь используют `odyssey.compact.generate`.
[Разбор известных карт и применённые приёмы](docs/mapmaking-patterns.md).

Автопроверки читают записанные задания и стражей, проверяют цепочку знаков,
пути от пляжей и последовательное открытие островов. Проверка обходов допускает
восемь направлений и произвольную высадку: будущие острова и морские бои должны
оставаться закрыты даже в такой разрешающей модели. Проверяются и намеренно
сломанные варианты: удалённый риф, неверный ключ, тупик в цепочке. Эти проверки не заменяют
проверку редактором и полный игровой прогон; их статус указан в отчёте.

## MCP: инструменты для ИИ

Локальный сервер предоставляет просмотр и проверку карт, поиск объектов,
генерацию обычного мира и «Одиссеи», просмотр охраны, наград и активации событий,
правку названия, описания и численности отдельного отряда в новой копии.
Установка: `pip install -e ".[mcp]"`. Новые сборки идут в отдельные каталоги
`out/mcp/`. [Запуск, подключение к Codex, инструменты и ограничения](docs/mcp.md).

Нативные награды, охрана ящиков и события HotA revision 9 доступны через
`h3m.adventure.Reward`. [Разбор руководств по картам и принятые решения](docs/mapmaking-notes.md).

## Требования

- Python 3.12+
- Установленная Heroes III + HotA (для тестов на реальных картах)

Путь к игре ищется автоматически, переопределяется переменной окружения:

```bash
set H3_GAME_DIR=C:\Games\Heroes of Might and Magic III Complete
```

## Установка

```bash
pip install -e ".[dev]"
```

## Структура

```
src/h3m/          ядро: разбор и сборка формата
src/odyssey/      прикладное: генератор карты по «Одиссее»
tools/            утилиты командной строки (дампы, диффы, отчёты)
tests/            тесты, в том числе round-trip по реальным картам
journal/          рабочий журнал и решения (ADR) — локально, не в git
logs/             логи прогонов (не в git)
out/              сгенерированные карты (не в git)
reference/        заметки по формату; сами карты игры — не в git
```

## Лицензионная оговорка

Проект не содержит и не распространяет данные Heroes III или Horn of the Abyss.
Для работы с реальными картами нужна собственная легальная копия игры.
Формат `.h3m` разбирается для целей совместимости.
