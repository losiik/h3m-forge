# h3m-forge

Библиотека для чтения, записи и генерации карт Heroes of Might and Magic III
(`.h3m`), с прицелом на формат Horn of the Abyss.

ИИ-агент описывает главы, задания, награды и зависимости в JSON;
генератор строит острова, закрывает будущие этапы, расставляет подсказки
и собирает родной файл HotA. Для каждого нового сюжета писать Python не нужно.

## Статус

Есть ридер/райтер, генератор миров из зон и генератор одиночных сюжетных
приключений из графа глав. MCP-сервер предоставляет 18 инструментов.
Новые `catalog_search` и `catalog_get` дают [справочные карточки игры](docs/game-catalog.md):
189 существ, 164 артефакта и 8 заклинаний, с источниками и подробными схемами
ответов. Для 49 существ HotA числовые поля сверены с документацией и файлами
игры; доступны профили 1.8.0/1.8.1. Все девять базовых фракций имеют по
14 существ: их справочные таблицы дополнены подтверждёнными изменениями HotA.
Неподтверждённые актуальные AI value явно равны null.
У 16 сборных артефактов указаны компоненты, занимаемые группы слотов и
раздельные бонусы набора/частей. Условные эффекты сохраняют ограничения.
Поддерживаемый сюжетный профиль — морской архипелаг 72×72, 2–16 глав.
Полный игровой баланс автоматически не проверяется.

## Собственное сюжетное приключение

```powershell
python -m pip install -e '.[mcp,dev]'
python -m h3m.scenario_cli examples/last-beacon.json --game-dir 'C:\Games\Heroes of Might and Magic III Complete'
python -m h3m.scenario_cli examples/three-councils.json --game-dir 'C:\Games\Heroes of Might and Magic III Complete'
```

Через MCP агент читает `h3m://scenario-example`, уточняет доступных существ
через `scenario_catalog` и передаёт описание в `generate_scenario(spec)`.
Результат — новый каталог с `map.h3m`, `report.json`, `specification.json`
и `walkthrough.md`. Исходные и установленные карты сохраняются.

Поддерживаются обязательные и необязательные ветки, схождение нескольких
этапов, сухопутные и морские бои, передача ресурсов, войск и предметов,
охраняемые награды, девять почв, обзор островов и указатели маршрута.
Проверяются высадки, расстояния, обходы закрытых этапов и достижимость финала
без необязательных наград; расход припасов учитывается, потери в боях — нет.

[Руководство генератора и границы поддержки](docs/scenario-generator.md).
Два независимых примера: [«Последний маяк»](examples/last-beacon.json)
и [«Совет трёх»](examples/three-councils.json).

## Генератор миров HotA

Независим от сценария «Одиссеи». Вход — JSON с зонами, их почвами,
стартовыми игроками и связями. Выход — **родной формат HotA 1.8.0,
подверсия 9**, карта `.h3m` и отчёт `.report.json`.

После установки проекта:

```powershell
python tools/make_world.py examples/archipelago.json --output out/archipelago.h3m
python tools/make_world.py examples/archipelago.json --seed 123 --output out/archipelago-123.h3m
```

Пример: [examples/archipelago.json](examples/archipelago.json). Название, размер
(72, 108, 144), seed, набор из 2–8 зон, их почвы и связи редактируются в JSON.
Каждому игроку нужна ровно одна стартовая зона; номера игроков идут от 0
без пропусков, игроков минимум два. Связи должны объединять все зоны.
`decoration_density` задаётся от 0 до 0.4. Неизвестные поля отклоняются.

Генератор создаёт острова с широкими сухопутными переходами, стартовые города,
лесопилки, рудники, ресурсы, сундуки и наборы декора по биомам. Переходы почв
и береговые тайлы подбираются по окружению 3×3 из установленных карт вместе
с флагами отражения. Если подходящего образца нет, генерация завершается
ошибкой. Каталог кэшируется в `out/world-assets.json` и пересчитывается при
изменении исходных карт. Первый запуск существенно дольше повторных.

Проверяется полный разбор файла, побайтовая пересборка, отсутствие пересечений
занятых клеток объектов и доступность зон и южных подходов к интерактивным
объектам после размещения декора. Проверка проходов использует только шаги
по сторонам клеток, без зависимости от возможности срезать угол.

Этот отдельный генератор миров имеет более узкий набор игровых механик:
пока один наземный слой, без плавания, охраны, баланса боёв, дорог, квестов
и скриптов. Связи гарантируют доступ, но не запрет обхода и не порядок
прохождения. Геометрия размещает зоны по окружности. Произвольные формы,
подземелье и обязательные охраняемые проходы требуют следующих алгоритмов.
Прохождение партии в игре пока не проверено.

Базовый `h3m.generate.new_map()` сохраняет формат SoD для прежних инструментов;
новый `h3m.hota.new_map()` и `h3m.world.generate_world()` создают HotA.

| Фаза | Что                               | Статус                |
|------|-----------------------------------|-----------------------|
| 0    | Каркас, логирование, журнал       | готово                |
| 1    | Ридер `.h3m` (все версии)         | готово для RoE/AB/SoD |
| 2    | Райтер и round-trip               | готово                |
| 3    | Генерация карты с нуля            | готово                |
| 4    | Карта по мотивам «Одиссеи»        | в работе              |
| 5    | MCP-сервер с семантическим API    | 18 инструментов, stdio; PNG/текст карты, собственные сценарии, справочные карточки и правка отрядов |
| 6    | Сюжетный генератор из JSON       | 72×72, 2–16 глав, ветки, задания и проверка прохождения в модели |

Сгенерированные карты открываются в редакторе HotA: пустая, с объектами и со
стартовыми городами — проверено вручную.

**RoE, AB и SoD разобраны полностью — 100% байтов.** Каждая из 157 карт этих
форматов читается до последнего байта и собирается обратно побайтово.

| формат | карт | round-trip | разобрано |
|--------|------|------------|-----------|
| RoE    | 47   | 47/47      | 100% |
| AB     | 54   | 54/54      | 100% |
| SoD    | 56   | 56/56      | 100% |
| HotA   | 64   | 64/64      | 68%  |
| всего  | 221  | 221/221    | 88%  |

У HotA остались собственные надстройки над несколькими типами объектов:
хижина провидца, герои, события, монстры.

## Как проверяется корректность

Ключевая идея проекта — **round-trip побайтово**:

```
оригинал.h3m → ридер → структура → райтер → новый.h3m
                                               ↓
                            сравнение с оригиналом байт в байт
```

Если реальная карта из поставки игры разбирается и собирается обратно без
единого расхождения, значит формат понят точно, а не «примерно похоже».
Это доказывает сохранность байтов, но не правильную интерпретацию каждого
поля: непрочитанные блоки могут сохраняться сырым хвостом, а симметричная
ошибка чтения/записи тоже выдержит round-trip. Поэтому отдельно проверяются
полнота разбора, семантика карты и открытие в редакторе.

Второй инвариант, бесплатный и очень полезный: парсер обязан дойти ровно до
конца потока. Остался лишний байт или не хватило — значит где-то поехало
смещение.

Тестовая база — 221 карта из поставки HotA 1.8.0.

## Сюжетная «Одиссея» для HotA

```powershell
$env:PYTHONPATH='src'
python tools/make_odyssey_story.py
```

Результат: `out/Odyssey-Homecoming-Labyrinth.h3m`
(«Одиссея: лабиринт Посейдона»), руководство `.md` и отчёт `.report.json`.
Переработка 11 сохраняет эпизоды мифа и подземное царство теней, но связывает
бухты извилистыми проливами в общем массиве суши. Старые кольца рифов вокруг
каждого эпизода удалены; леса, дюны и скалы закрывают берега. Стражи закрывают саму основную дорогу. Две боковые бухты
с охраняемыми наградами позволяют отклониться от неё и вернуться.

Зависимость второго разговора с Эолом от короны удалена. Раньше предмет
выдавался невидимым событием на клетке высадки; модель ошибочно засчитывала
награду даже при достижении соседней клетки. Теперь раскрытие меха — видимый
бой с вырвавшимися ветрами, а разговор проверяет победу над конкретным отрядом.

Общий обзор убран: карта открывается исследованием. Длинные указания курса
заменены местными задачами. Старт — 8 алебардщиков, 6 арбалетчиков и 2 мечника.
Щит, Лечение, Благословение, Замедление и Ускорение доступны сразу.
Воскрешение можно отбить в лагере у Полифема; магия земли уже изучена.
Автоматического пополнения маны на стоянках нет. Шляпа адмирала сохраняется.
Всего 41 столкновение с учётом необязательных, из них 12 морских, включая три засады.
На острове ложной Итаки бой с ветрами теперь происходит на суше: он
открывает следующий пролив. В хижине можно забрать трёх спасённых
арбалетчиков. Вместо бесконечного колодца — охраняемый тайник с 12 маны.
Трофеи остаются только в семи особых боях; обычные бои не дают золота.
На Трое добавлена мастерская боевых машин, а в охраняемый обоз — 2250 золотых
на баллисту и палатку. Эол выдаёт меч (+6 к нападению) перед зелёными драконами;
усилены три засады и охрана 13 ящиков. После появления машин численность
первых двух засад утроена; в последней — 5 древних чудищ. В проливе стоят 200 сирен. На их острове добавлена охраняемая
Чаша тишины: экспертная Мудрость и разовые +30 маны.
Доход стартового лагеря уходит на содержание флота. На берегах — четыре охраняемых испытания наставников;
у Сциллы и Харибды — выбор аспидов или гидр. На острове перед развилкой
можно отбить магический колодец у 30 воров и 15 кочевников; после боя
колодец остаётся доступен. Артефакты можно применить
задолго до необязательного обмена. Платы за проход и сдачи солдат нет.
Первый архангел даётся за обязательную засаду перед последним актом,
второй — за усиленное необязательное испытание феаков. Финал — синий Антиной
с сильной дружиной и городским наймом стрелков. Дополнительные подкрепления
приходят на 15, 29 и 43-й день; обычный рост стрелков продолжается.
По отзыву о финале Воскрешение убрано из книги Антиноя, его начальные
нападение/защита/сила магии/знания снижены до 12/12/5/4.

Проверяются 16 высадок, в том числе новые бухты, и реальная стартовая армия
из файла карты. Основной сюжет отдельно проверяется без необязательных наград
и платных услуг. Морские переходы: максимум 29 клеток; путь к действию
от пляжа — не более 12 клеток.
Проверка обходов допускает восемь направлений и произвольную высадку;
непроходимая суша закрывается настоящими масками объектов.

Модель предполагает победы без потерь, поэтому сложность боёв и длительность
не считаются проверенными игровым прогоном. Сюжетные награды и фиксированные
отряды доступны на всех пяти сложностях (80–200%). Начните новую игру:
старые сохранения содержат старую карту. Генераторы `odyssey.story`,
`odyssey.playable` и `odyssey.compact` сохранены для воспроизведения прежних
версий; CLI и MCP используют `odyssey.well_journey.generate`.
[Колодец на острове Сциллы и Харибды, редакция 12](docs/odyssey-well.md).
[Редкие награды и усиленный финал](docs/odyssey-siege.md).
[Малый отряд, восстановление и баланс](docs/odyssey-small-company.md).
[Награды, развилка и новый финал](docs/odyssey-rewards.md).
[Причины и устройство переработки](docs/odyssey-labyrinth.md).

## MCP: инструменты для ИИ

Локальный сервер предоставляет просмотр и проверку карт, поиск объектов,
изображение и координатную разметку карты без Computer Use,
генерацию обычного мира и «Одиссеи», просмотр охраны, наград и активации событий,
правку названия, описания и численности отдельного отряда в новой копии.
Установка: `pip install -e ".[mcp]"`. Новые сборки идут в отдельные каталоги
`out/mcp/`. [Запуск, подключение к Codex, инструменты и ограничения](docs/mcp.md).

В PyCharm можно запускать корневой `main.py` кнопкой Run.
[Установка зависимостей, выбор интерпретатора и подключение Claude/ChatGPT](docs/mcp-other-agents.md).

Нативные награды, охрана ящиков и события HotA revision 9 доступны через
`h3m.adventure.Reward`. [Разбор руководств по картам и принятые решения](docs/mapmaking-notes.md).

Для новых сюжетных карт MCP принимает `spec.balance_profile="fixed"`:
фиксированная охрана и награды на 80–200%, без роста нейтралов, случайных
улучшений, особых месяцев и городского найма. Численность задаёт автор,
тактический баланс проверяется отдельно. [Готовый пример](examples/fixed-company.json).

## Требования

- Python 3.12+
- Установленная Heroes III + HotA (для тестов на реальных картах)

Путь к игре ищется автоматически, переопределяется переменной окружения:

```bash
set H3_GAME_DIR=C:\Games\Heroes of Might and Magic III Complete
```

## Установка

```bash
pip install -e ".[dev]"
```

## Структура

```
src/h3m/          ядро: разбор и сборка формата
src/odyssey/      прикладное: генератор карты по «Одиссее»
tools/            утилиты командной строки (дампы, диффы, отчёты)
tests/            тесты, в том числе round-trip по реальным картам
journal/          рабочий журнал и решения (ADR) — локально, не в git
logs/             логи прогонов (не в git)
out/              сгенерированные карты (не в git)
reference/        заметки по формату; сами карты игры — не в git
```

## Лицензионная оговорка

Проект не содержит и не распространяет данные Heroes III или Horn of the Abyss.
Для работы с реальными картами нужна собственная легальная копия игры.
Формат `.h3m` разбирается для целей совместимости.
