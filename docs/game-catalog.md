Добавлены 49 существ: все 15 войск Причала, 16 Фабрики (включая полурослика),

служебные записи не считаются обычными существами. Города и здания ещё

Русские названия также принимаются, например:

Каталог встроен в Python-пакет, работает без игры, сети и Computer Use.
Снимки поддерживают HotA **1.8.0 и 1.8.1**. По умолчанию возвращается 1.8.1;
для установленной у пользователя 1.8.0 нужно передавать `ruleset="hota_1.8.0"`.
Каталог не определяет версию игры автоматически и не обновляет её.

## Поиск

Вызов `catalog_search`:

```json
{"category":"artifacts","query":"защита от ослепления","limit":10}
```

Ответ содержит Кулон ясновидения, ID 101. Параметры:

| Поле | Значение |
|---|---|
| `category` | `artifacts`, `creatures`, `spells`; можно опустить |
| `query` | Название, псевдоним, ID или слова из описания/тегов; до 256 символов |
| `tag` | Точное значение тега из предыдущего ответа |
| `faction` | Ключ фракции существа: например, `castle`, `stronghold`, `neutral` |
| `ruleset` | `hota_1.8.0` или `hota_1.8.1` (по умолчанию); также принимается `catalog_get` |
| `offset`, `limit` | Страница; offset от 0, limit от 1 до 200, по умолчанию 20 |

Поиск учитывает все слова запроса, регистр и ё/е не различает. Это поиск
по тексту, не семантическая модель и не расчёт подходящего баланса.
Новые ключи фракций: `cove`, `factory`, `bulwark`.
Ответ: `items`, `total`, `next_offset`, `coverage`, `catalog_version`, `ruleset`,
`limitations`. Список короткий; характеристики берутся отдельным вызовом.

## Подробная карточка

Вызов `catalog_get`:

```json
{"category":"creatures","id":97}
```

Это древнее чудище, а не громовая птица. ID относится к своей категории:
номера артефактов, заклинаний и существ нельзя подменять друг другом.

| Часть карточки | Поля |
|---|---|
| Общая | ID, ключ, имена RU/EN, псевдонимы, описание, теги |
| `creature` | Фракция, уровень, здоровье, скорость, нападение, защита, диапазон урона, выстрелы, прирост, стоимость, AI/Fight value, улучшения и эффекты |
| `artifact` | Слоты, справочная стоимость, класс, собственные и унаследованные эффекты, компоненты, итоговые бонусы и доступность по умолчанию |
| `spell` | Школа, уровень, цель, мана и эффект для четырёх уровней владения магией, массовость, известные требования |
| Проверка | `reference_ruleset`, `target_ruleset`, `verification`, `source_ids`, `version_notes` |
| Генератор | `scenario_support`: поддержан, не поддержан или требуется шаблон из установленных карт |

Заполнен только один из блоков `creature`, `artifact`, `spell`.
Корневой ответ содержит `found`, `item`, `sources`, `message`, `limitations`.
Нимфа 153 теперь доступна: 4 здоровья, нападение 5, защита 2, цена 35 золота.
Для неохваченного ID (например, 65000) вернётся `found=false`; это означает
отсутствие карточки, а не доказательство отсутствия существа в игре.

Пример различия версий:

```json
{"category":"creatures","id":197,"ruleset":"hota_1.8.0"}
```

Боевой мамонт: `ai_value=1601`, `fight_value=1601`. С `hota_1.8.1` оба значения
равны 1672. `version_notes` поясняет изменение и отличие стандартной награды
Пандоры от авторского состава ящика. Прочие новые числовые поля:
`horde_growth` (добавочный прирост от здания), `map_amount_min/max` (типовой
размер случайного отряда). Они не подменяют состав охраны в конкретной карте.
Для базовых карточек эти числовые поля взяты из справочных таблиц; известные
изменения HotA применены отдельно. Если изменение AI value подтверждено,
но актуальное число неизвестно, `ai_value=null`.

В `effects` есть структурированные признаки и краткие описания способностей
(`type=DOCUMENTED_ABILITY`, `description`). Это не исполняемые формулы боя;
неполнота механик явно указана в `verification.unknown_fields`.

Пример для магии:

```json
{"category":"spells","id":38}
```

Карточка Воскрешения содержит цену маны по уровням, формулу здоровья,
признак постоянного восстановления и требование продвинутой Магии земли
(навык 17, уровень 2). Требование Мудрости указано для обычного изучения
заклинания четвёртого уровня. Каталог не проверяет фактическую книгу героя.

## Источники и границы

ID и механики сверены с VCMI, закреплённым на ревизии
`77eee6cb12b04d0f68f3d970b64c1bf97bb1c374`. Числовые таблицы характеристик,
цен и затрат маны взяты из локальных CRTRAITS/ARTRAITS/SPTRAITS пакета
SuperPack_Rus 1.5. В карточках перечислены источники и их SHA-256;
полные игровые тексты и файлы игры в каталог не включены.

Для новых существ числовые поля сверены между
[официальной документацией HotA](https://h3hota.com/en/documentation)
и нативными записями установленного `HotA.dat` 1.8.0. Изменения 1.8.1 взяты
из [официального журнала](https://download.h3hota.com/upd/changelogs/eng.txt).
ID полурослика 138 дополнительно сверяется с закреплённым VCMI; его базовые
числа — с CRTRAITS, а принадлежность Фабрике — с документацией HotA.
Fandom, предложенный пользователем, вернул 403 при скачивании; его содержимое
не использовано. Сборщик разбирает числовые разделы официального HTML,
проверяет все выбранные поля и останавливается при расхождении.

Новые карточки имеют `verification.properties=official_documentation_and_native_data`.
У базовых карточек стоит `properties=reference_only` либо
`reference_with_documented_hota_changes`; происхождение базы указано как
`reference_ruleset=heroes3_reference`. Выбор версии **не превращает** эти
данные в полностью проверенные значения HotA. У всех `hota_runtime=not_verified`:
играющий процесс и сторонние моды не исследовались. AI/Fight value не
доказывает трудность или проходимость боя.

Применены подтверждённые поправки HotA: цены элементалей мысли/магии и
огненных птиц/фениксов, прирост птиц, огненная защита птицы вместо иммунитета,
удача архидьявола −2, AI/Fight ящеров и султана ифритов, случайная численность
снайперов. Изменения площадной стрельбы и циклопов отражены в `version_notes`.
У монаха 8, наги 38, призрачного дракона 69, скорпикоры 81, красного дракона 82,
короля циклопов 95, огненной птицы 130 и сказочного дракона 134 актуальный
AI value оставлен неизвестным: документация сообщает изменение без числа.
Это указано также в `verification.unknown_fields`.

`scenario_support` относится именно к `generate_scenario`: например,
кулон 101 существует в справочнике, но не входит в текущий диапазон
артефактов этого генератора. Генератор «Одиссеи» имеет отдельные правила.
Для существ наличие нативного шаблона выясняется при генерации.

Дальнейшее наполнение: полная сверка базовых характеристик с HotA, взаимодействия артефактов,
города и здания, объекты местности, составные артефакты и более полные
условия применения эффектов. Новые категории сейчас не заявляются.

## Обновление и проверка

`tools/build_game_catalog.py` воспроизводит базовый снимок из закреплённых JSON
VCMI всех девяти фракций и нейтралов и явно указанной папки таблиц.
`tools/base_hota_changes.py` применяет подтверждённые поправки; для сборки
нужны также снимки официального HTML и журнала изменений. Он не скачивает источники и не меняет
карты. Снимок: `src/h3m/data/game_catalog.json`; контракт ответов:
`src/h3m/catalog_contract.py`; поиск: `src/h3m/game_catalog.py`.

`tools/build_hota_catalog.py` отдельно воспроизводит
`src/h3m/data/hota_creatures.json`, поэтому пересборка базовой выборки не
стирает дополнение HotA. В `--references` нужны `hota-documentation-en.html`,
`hota-changelog-en.txt`, `config_creatures_neutral.json`, `vcmi-commit.txt`.
Укажите также `--game-dat` (снимок 1.8.0) и `--tables` (SuperPack_Rus 1.5).
Скрипт не скачивает данные сам и не исполняет их. Повреждённая структура,
неожиданный ID, пропущенное поле или несогласованное число вызывают ошибку
до записи результата. При новом релизе нужен новый аудит различий.

Полные HTML и файлы игры не распространяются в Python-пакете. Встроены
извлечённые факты, краткие собственные пояснения, URL и хеши источников.

```powershell
.venv-mcp/Scripts/python.exe tools/export_mcp_catalog.py
```

Эта команда получает реальные схемы MCP и примеры ответов в `out/`.
После обновления пакета перезапустите ранее подключённый MCP-сервер,
чтобы клиент обнаружил `catalog_search` и `catalog_get`.

## Артефакты и сборные наборы

Добавлены все базовые ID 0–140 и HotA 141–143, 146–165: 164 карточки,
включая 16 сборных артефактов, книгу, свиток и боевые машины. Резервные
номера 144/145 исключены. Пушка — артефакт 146, но существо-машина 150;
категория всегда обязательна при запросе конкретного ID.

```json
{"category":"artifacts","tag":"сборный"}
```

Это аргументы `catalog_search`; для подробностей:

```json
{"category":"artifacts","id":160,"ruleset":"hota_1.8.0"}
```

Золотой гусь: `components=[117,116,115]`, собственный доход 4750,
доход компонентов 2250, `effective_daily_income.gold=7000`.
Компоненты и бонус сборки **не надо повторно прибавлять к итоговому полю**.

| Поле | Смысл |
|---|---|
| `components` | ID частей; `[]` означает обычный артефакт |
| `effects` | Только собственные эффекты предмета или бонус сборки |
| `component_effects` | Эффекты частей, с `source_artifact_id`; некоторые могут перекрываться способностью набора |
| `effects_include_components` | `false`: части вынесены отдельно |
| `effective_primary_skills` | Суммарные безусловные прибавки к четырём навыкам героя |
| `effective_daily_income` | Суммарный доход в день, включая компоненты |
| `assembly_slots` | Требуемые группы слотов и количество, например `ring:2` или `misc:3` |
| `default_availability` | Известный запрет по умолчанию либо `not_verified`; настройки карты могут отличаться |
| `effects[].parameters` | Условия, ограничения целей, особенности сложения и другие поля источника |

Например, усиление драконов от Фиала драконьей крови не превращается в
прибавку к навыкам героя: ограничение `DRAGON_NATURE` сохраняется.
Для Оков войны явно требуется наличие героев с обеих сторон.

У базовых 12 наборов непроверенный слот главной иконки обозначен `slot=[]`
и записью в `unknown_fields`; нужные места для компонентов известны через
`assembly_slots`. Это не означает, что набор предназначен только для рюкзака.
Их `artifact_class=combination` — категория показа, а не подтверждённое
значение нативной редкости. У новых наборов HotA главный слот сверяется
между документацией и локальными данными.

Учтены цена баллисты 1500, бонусы движения перчаток 200 и сапог 400,
восстановленные в HotA 1.8.0 бонусы некромантии, запреты по умолчанию,
Кольцо забвения и Накидка молчания. `cost_gold` — справочная стоимость;
это не обещание конкретной цены покупки или продажи на любой карте.

Предложенная [страница артефактов](https://pro-onlineigry.ru/homm3/artefakty-i-sety)
разобрана как HTML-таблицы. 56 карточек сопоставлены по точному нормализованному
имени для дополнительной сверки цены. Страница не служит источником ID;
расхождения отмечаются, приоритет имеют основные источники. Полный текст
статьи не включён в пакет. ID и бонусы базы берутся из закреплённого VCMI,
числа и слоты — из ARTRAITS; новые артефакты — из HotA.dat с проверкой по
официальной документации. Составы сборных артефактов тоже имеют ссылки
на источники компонентов.

`tools/build_artifact_catalog.py` строит отдельный
`src/h3m/data/artifact_catalog.json`, который целиком заменяет прежнюю
выборку из десяти артефактов при чтении каталога. Входы: `--references`,
`--tables`, `--game-dat`; в references нужны закреплённые `config_artifacts.json`,
`vcmi-commit.txt`, снимки официальных документации и журнала и
`pro-onlineigry-artifacts.html`. Сборщик не скачивает и не исполняет входы.
Проверки отклоняют повреждённые записи, неизвестные ID и циклы сборки.
